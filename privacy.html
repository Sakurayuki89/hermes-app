개인정보처리방침 (Privacy Policy)

시행일: 2026-10-23

1. 사용하는 Google 권한

Hermes는 사용자(개발자 본인)가 Google 로그인 화면에서 직접 승인한 권한(예: Gmail, Google Drive 등)만 사용하며, 요청을 처리하는 데 필요한 범위 안에서만 해당 데이터를 읽고 씁니다.

2. 데이터 저장

로그인 토큰(OAuth token)은 본인 Mac에만 저장되며 외부 서버에 업로드하거나 제3자와 공유하지 않습니다. Google 데이터는 별도의 서버나 데이터베이스에 보관하지 않습니다.

3. AI 모델 제공자로의 전송

대화 내용과 요청 처리에 필요한 Google 데이터는 AI 모델 제공자(OpenRouter)로 전송되어 응답 생성에 사용됩니다. 이 외의 목적으로는 전송하지 않습니다.

4. Limited Use

Hermes's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, is not sold, and is not read by humans except as needed by the user (the developer) himself.

5. 권한 철회 / Revoking access

https://myaccount.google.com/permissions 에서 Hermes의 접근 권한을 언제든 삭제할 수 있습니다. 삭제하면 저장된 토큰은 더 이상 사용할 수 없습니다.
