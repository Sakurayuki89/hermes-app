Privacy Policy

Last updated: 2026-10-23

Who uses this app

hermes is used only by its owner, with the owner's own Google account. No other person's account is connected.

Google data accessed

With the owner's consent, hermes may access: Google Calendar (read and create events), Gmail (read, send, label), Google Drive, Docs and Sheets (read and edit files), and Google Contacts (read only). Access happens only when the owner asks for a task.

How data is used and stored

  • Data is used only to carry out the owner's request (for example, adding an event the owner asked for).
  • OAuth tokens and notes are stored on the owner's own computer. There is no separate server or database.
  • To understand a request, the text of the conversation and the Google data needed for it are sent to an AI model provider (OpenRouter, routing to the model in use). That data is processed only to answer the request.
  • Data is not sold, not used for advertising, and not shared with anyone else.

Limited Use

hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

The owner can revoke access at any time at myaccount.google.com/permissions and delete the locally stored token files.
